# KurobaEx v1.3.47-experimental.6

Fixes response handling and cookie expiry:

- Ordinary HTTP 403 and 503 error responses remain readable after Cloudflare detection, preserving the server error message.
- Detected Cloudflare challenge responses release their HTTP connections before verification or retry.
- Cookie Max-Age takes precedence over Expires regardless of attribute order, including cookie deletion.

Includes regression tests for response ownership, connection reuse, and cookie expiry. Retains the existing playback changes and fixed media action placement from experimental.5.

Install manually over the previous Experimental build. The package and signing key are unchanged, so existing Experimental data and settings are retained. The app is KurobaEx Experimental, package `com.github.k1rakishou.chan.experimental`, with separate data from Personal and upstream builds. Android 6.0 or newer is required.

For manual testing, check normal browsing and posting, Cloudflare verification and retry when encountered, and readable server error messages. The cookie attribute-order cases are covered by automated tests. This build is a testing candidate; device behavior has not yet been verified.
