# KurobaEx v1.3.47-experimental.4

Adds Next post to the media viewer's action controls. The button advances to the next post with media, skips remaining attachments from the current post, and disables at the last available post. Swiping remains available.

The button sits beside the bottom media controls on phones and follows the existing side controls on tablets. It has a 48 dp tap target and the accessibility label Next post. Existing control ordering is retained, with Next post at the end.

Install manually over the previous Experimental build. The package and signing key are unchanged, so existing Experimental data and settings are retained. The app is KurobaEx Experimental, package `com.github.k1rakishou.chan.experimental`, with separate data from Personal and upstream builds. Android 6.0 or newer is required.

This candidate awaits user testing before the release branch is pushed or the release is published. Test button navigation, swiping, multiple attachments, the last available post, and portrait/landscape placement.
