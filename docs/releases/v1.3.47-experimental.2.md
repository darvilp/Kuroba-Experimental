# KurobaEx v1.3.47-experimental.2

Updated to upstream KurobaEx v1.3.47 while retaining this fork's Media3 1.10.1 playback, Loop/AutoAdvance/Stop controls, inactive-player cleanup, paused-video restoration, and Samsung VP8 operating-rate experiment.

## Changes

- Upstream sound-post playback now uses a separate audio player synchronized with video, including MPV. The new player uses Media3 in this fork. AutoAdvance waits for the complete linked-audio cycle when the video is shorter.
- Upstream MPV request-header support, smoother seekbar and buffering/error feedback.
- Upstream posting, email verification, cookie refresh, Lynxchan, WebView, scrollbar, and notification-permission fixes.
- Cookie migration follows the fork's existing video-preference migration. Existing Loop, Stop, or AutoAdvance choices are preserved, including installations with an unset migration version.

## Install or update

Choose **universal** if unsure, or **arm64-v8a** for most recent Android phones. Android 6.0 or newer is required. Install the APK manually over the previous Experimental build; the signing key and application ID are unchanged, so its data and settings are retained.

The app is **KurobaEx Experimental**, package `com.github.k1rakishou.chan.experimental`. It installs alongside upstream and Personal builds with separate data. The built-in updater is disabled. MPV libraries are installed/configured through the app as usual.

## Validation and feedback

Automated validation includes Android unit tests, Detekt, release-tool tests, and APK package/version/debuggable/signature/commit/architecture/checksum verification. This release has not been tested on a physical device. The Samsung VP8 change remains experimental.

Test short-video/long-audio sound posts, each completion option, paused-video revisits, and background/foreground playback. Reports should include the version, Android version, device model, selected player, completion option, and reproduction steps. Remove private URLs and account data from shared logs.

`SHA256SUMS.txt` records the APK hashes. `release-manifest.json` records the source commit and public signing-certificate fingerprint. Signing credentials remain local.
