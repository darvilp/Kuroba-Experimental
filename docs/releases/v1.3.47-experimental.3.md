# KurobaEx v1.3.47-experimental.3

Maintenance update to v1.3.47-experimental.2 with the reviewed code-style cleanup. Retains upstream v1.3.47, Media3 playback, Loop/AutoAdvance/Stop controls, sound-post synchronization, paused-video restoration, and the Samsung VP8 operating-rate experiment.

## Changes

- Reuse the existing safe coroutine-continuation helpers during player preparation, preserving listener cleanup and playback behavior.
- Align player imports and method placement with surrounding repository conventions.
- Clarify regression-test setup without changing the assertions.

## Install or update

Choose **universal** if unsure, or **arm64-v8a** for most recent Android phones. Android 6.0 or newer is required. Install manually over the previous Experimental build. The application ID and signing key are unchanged, so existing Experimental data and settings are retained.

The app is **KurobaEx Experimental**, package `com.github.k1rakishou.chan.experimental`. It installs alongside upstream and Personal builds with separate data. The built-in updater is disabled. MPV libraries are installed/configured through the app as usual.
