# KurobaEx v1.3.44-experimental.1

Initial tester build of this fork's experimental playback channel, based on KurobaEx v1.3.44.

## Included changes

- Media3 1.10.1 playback.
- Playback lifecycle fixes that stop inactive video pages from holding prepared decoders.
- Loop, AutoAdvance, and Stop options for video completion, with MPV completion support.
- Samsung VP8 operating-rate experiment and diagnostic logging.
- A fix for AutoAdvance after pausing a video, swiping away, returning, and pressing Play.
- Completion-listener cleanup when a player returns to the reusable pool.

The VP8 change remains experimental. Device performance and decoder behavior can vary.

## Install

Choose the universal APK if you are unsure which CPU architecture your device uses. ARM64 is suitable for most recent Android phones. Android 6.0 or newer is required.

This app is named **KurobaEx Experimental** and uses package `com.github.k1rakishou.chan.experimental`. It installs alongside upstream KurobaEx and the earlier Personal app. It has separate data and settings, so it does not automatically inherit those installations' configuration.

These APKs use a dedicated signing key and are not debuggable. Future experimental builds signed with the same key will update this experimental installation. The built-in updater is disabled for this channel; install each APK update manually from the source provided by the project maintainer.

## Test and report

Try video playback with each completion option, switching between media pages, returning to a paused video, and backgrounding and restoring the viewer. For MPV, install or configure its libraries through the app as usual.

For playback reports, include this release version, Android version, device model, selected player, completion option, and steps to reproduce. Review logs before sharing them and remove account information and private URLs.

`SHA256SUMS.txt` lists the APK hashes. `release-manifest.json` records the exact source commit, version, and signing certificate fingerprint.

Validation includes automated unit tests, Detekt, release assembly, and APK identity/signature/checksum verification. Physical-device verification of this release is not included.
