# KurobaEx v1.3.47-experimental.5

Keeps Next post at the same tap position when switching between images, GIFs, and videos on phones. The shared media action row now sits immediately above the system navigation area, with video and sound-post playback controls above it. Tablet side controls retain their existing placement.

Next post navigation, swiping, the saved control order, and the disabled button at the last available post are unchanged. This build retains the existing cumulative Media3 playback changes and Samsung VP8 operating-rate experiment.

Install manually over the previous Experimental build. The package and signing key are unchanged, so existing Experimental data and settings are retained. The app is KurobaEx Experimental, package `com.github.k1rakishou.chan.experimental`, with separate data from Personal and upstream builds. Android 6.0 or newer is required.

This candidate awaits user testing before either branch is pushed. Check repeated Next post taps across image and video transitions, playback controls, sound posts, portrait and landscape, and system navigation spacing.
